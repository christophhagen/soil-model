# Security Policy

## Supported versions

SoilModel is under active development. Security fixes are applied to the latest
release (or the `main` branch until the first release). Please report any issue
regardless of the version it was found in.

## Reporting a vulnerability

Do **not** open a public issue for a security concern.

Instead, report the issue
[privately through GitHub](https://github.com/christophhagen/soil-model/security/advisories/new),
or by email to [github@christophhagen.de](mailto:github@christophhagen.de).
Please include as much of the following as you can:

- A description of the vulnerability and its impact
- Steps to reproduce, or a minimal reproduction
- Affected versions or commits
- Any suggested mitigation

You will receive an acknowledgement of your report, and updates on the progress
towards a fix.

## Disclosure

When a vulnerability is confirmed, a fix is released as soon as possible,
the reporter is credited (unless anonymity is requested),
and the issue is documented in the [CHANGELOG](CHANGELOG.md).

Vulnerabilities in the underlying SOIL framework should be reported to
[soil-core-swift](https://github.com/DLR-RB/soil-core-swift/security).
